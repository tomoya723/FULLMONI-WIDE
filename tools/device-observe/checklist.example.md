# 実機LCD 静的検証チェックリスト（例）

このファイルをコピーして実際の検証項目に書き換える。observe_agent.py に渡す。

## 表示レイアウト
- [ ] 画面全体が 800x256 相当で、欠け・黒帯・乱れが無い
- [ ] タコメータ(回転数)が中央に表示されている
- [ ] 車速の数値が読める位置に表示されている
- [ ] 水温・油圧・電圧のインジケータが所定の位置にある

## 数値・文字
- [ ] 数字が正しいフォント/桁で、にじみや化けが無い
- [ ] 単位表記 (rpm, km/h, ℃, V) が正しい

## 色・輝度
- [ ] 背景色・文字色が意図どおり（16bitカラーの色ずれが無い）
- [ ] 輝度が均一で、局所的な暗部・焼き付き・ムラが無い

## 警告・LED
- [ ] シフトライト/警告用 RGB LED (Neopixel ×8) の点灯状態が想定どおり
- [ ] 警告表示（マスターウォーニング等）が条件に合っている

## 判定の注意
- 撮影のブレ・映り込み・光ムラは「実機の不具合」ではないので issues に含めない
- 判断できない項目は notes に「要確認」と明記し、pass は false 側に倒す
